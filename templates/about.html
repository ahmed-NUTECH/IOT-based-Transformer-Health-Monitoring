About the Project

IoT Based Distribution Transformer Condition Monitoring System

Project Overview

The IoT Based Distribution Transformer Condition Monitoring System is an internship project developed to monitor the operating condition of a distribution transformer using Raspberry Pi and IoT technology. The system continuously collects real-time data including temperature, current, voltage, frequency, power factor and smoke condition. These parameters are analyzed to determine transformer health, generate intelligent reports, provide risk assessment, maintain historical data and allow users to download professional PDF reports through an interactive web-based dashboard.

System Features

Live Monitoring

Displays real-time transformer parameters.

Health Assessment

Automatic Normal, Warning and Critical evaluation.

Alerts

Instant abnormal condition notifications.

PDF Reports

Generate and download professional reports.

AI Prediction

Intelligent transformer condition analysis.

Interactive Dashboard

Visual charts for live monitoring.
